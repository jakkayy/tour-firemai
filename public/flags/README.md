# Flag icons

The SVG flags here come from [flag-icons](https://github.com/lipis/flag-icons) 7.6.0 (4x3 set), MIT licensed;
the licence is in `LICENSE`. Only the countries listed in `lib/countries.ts` are included, named by ISO code
(`jp.svg`); `eu.svg` is the European Union flag used for the Europe region.

`es.svg` is a simplified Spain (red and yellow stripes, no coat of arms): the original is 79 KB and the arms
cannot be made out at icon size.
